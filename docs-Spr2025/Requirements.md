# Requirements

## 1. Collect and preprocess data.

### Objective: Gather all necessary data, handle missing values, normalize variables, and merge data sources where needed.

## 2. Perform exploratory data analysis (EDA) to identify patterns and trends.

### Objective: Use descriptive statistics and visualizations to uncover key insights, correlations, and potential outliers. Detect and address outliers or anomalies in the dataset.

## 3. Use Machine Learning (ML) algorithms to further explore the data

### Objective: Use ML algorithms such as clustering and principal component analysis (PCA) to gain deeper insights

## 4. Create Interactive Visualizations.

### Objective: Create a dashboard that summarizes key findings with visualizations and allows users to filter and interact with the data. Use tools like Tableau, Power BI, or Python-based libraries.

## 5. Provide a detailed final report.

### Objective: Write a document summarizing all methods, results, and recommendations in a professional format.
